# 사이드바 업무 화면 연결

- 상태: 사용자 승인
- 승인일: 2026-10-25

## 반영 내용

- 사이드바의 준비 중 상태를 제거하고 대시보드, 확인 필요 사항, 테스트 시나리오, 테스트 케이스, 요구사항 커버리지, 변경이력을 실제 프로젝트 데이터에 연결한다.
- 문서 분석 내부의 생성 결과 목록과 사이드바 시나리오 메뉴의 중복을 제거한다.
- 테스트 케이스는 사용자가 선택한 시나리오만 대상으로 생성하며 검토 전·미실행 초안으로 저장한다.
- 확인 필요 결정과 생성 배치 작업을 변경이력에 기록한다.
- 로그인, 프로젝트 관리, 내보내기, 실제 테스트 실행은 이번 범위에 포함하지 않는다.
