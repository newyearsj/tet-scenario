# 인증·프로젝트 소유권 정책 변경

- 상태: 승인
- 승인 근거: 2026-10-26 사용자 구현 요청
- 적용 범위: FR-AUTH-01, NFR-04~06, NFR-10, TSA-AUTH-001, TSA-COM-001의 인증·세션·소유권

Google 단일 마스터 계정, 검증된 이메일과 Google `sub`, 7일 PostgreSQL 서버 세션, 프로젝트 소유권 경계, 사전 인증 데이터 격리 정책을 승인 변경으로 적용한다. 상세 구현 정책은 `policies/02-auth-integration.md`를 따른다. 기존 테스트 설계 업무 규칙은 변경하지 않는다.
