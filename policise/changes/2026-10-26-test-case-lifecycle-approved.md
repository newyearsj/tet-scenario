# 테스트 케이스 수명주기와 변경이력 완성

- 상태: 사용자 승인
- 승인일: 2026-10-26
- 대상: TSA-TC-001, TSA-TC-002, TSA-LOG-001, 대시보드 집계

## 승인 내용

- 테스트 케이스의 최초 생성 출처와 마지막 수정 출처를 분리한다.
- 사용자 수정과 AI 재생성은 코드 유지, 버전 증가와 이전 값 보존을 적용한다.
- 시나리오별 생성 성공·실패와 중복 요청 키를 저장한다.
- 상세 편집 전에 필수 필드, 단계별 기대 결과, 참조와 미결 질문을 검증한다.
- 변경이력에서 대상·작업·출처·기간을 필터링하고 변경 전후 요약을 조회한다.
- 대시보드는 실제 PostgreSQL 집계를 사용하고 삭제 요구사항을 제외한다.
