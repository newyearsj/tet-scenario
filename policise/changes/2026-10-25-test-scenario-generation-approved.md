# 문서 분석의 테스트 시나리오 생성 전환

- 상태: 사용자 승인
- 승인일: 2026-10-25
- 대상: 문서 분석 화면, OpenAI 분석 API, 시나리오 저장 구조

## 승인 내용

- 문서 분석의 주 목적을 기존 요구사항 변경 제안에서 새 테스트 시나리오 초안 생성으로 전환한다.
- 화면 탭은 `문서`, `시나리오 검토`, `생성된 시나리오`로 구성한다.
- 실제 업로드 문서의 요구사항·화면·역할·업무 규칙과 원문 근거를 연결한 시나리오만 저장한다.
- 자료에 없는 조건은 추측하지 않고 `확인 필요`로 표시한다.
- 기존 변경셋 데이터와 API는 과거 데이터 보존을 위해 삭제하지 않지만 새 문서 분석 흐름에서는 사용하지 않는다.
